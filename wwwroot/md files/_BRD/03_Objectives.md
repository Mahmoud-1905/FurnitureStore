# 3. Objectives

## 3.1 Functional Objectives
- **Digital Catalog:** Provide a highly visual, searchable, and filterable digital catalog showcasing all in-store furniture with precise dimensions, material details, and pricing.
- **Order Processing:** Enable end-to-end, seamless order processing, from an intuitive shopping cart to a secure, multi-step checkout workflow.
- **Showroom Integration:** Facilitate a robust showroom appointment booking system that perfectly synchronizes with the store manager's schedule, allowing customers to reserve times to inspect items physically.
- **Verified Reviews:** Implement a verified-purchase review system to build organic customer trust and social proof.
- **Operational Dashboard:** Deliver a comprehensive Store Manager dashboard for real-time inventory tracking, order fulfillment, and appointment management.

## 3.2 Non-Functional Objectives
- **Performance:** Ensure API response times remain under 500ms (95th percentile) and page rendering occurs within 2 seconds to prevent user drop-off.
- **Security:** Enforce strict security protocols, including JWT for API authentication, bcrypt for password hashing, and parameterized SQL queries to entirely prevent SQL injection attacks.
- **Reliability & Availability:** Target 99.5% system uptime, supported by automated daily database backups.
- **Usability & Accessibility:** Deliver a fully responsive web design (adapting seamlessly to mobile, tablet, and desktop) with WCAG 2.1 AA compliance and native, high-quality RTL (Arabic) support.
- **Scalability:** Utilize a stateless API design, leaning on Redis for efficient session management and data caching.

## 3.3 Academic & Learning Objectives
- Master the application of advanced system analysis and architectural design patterns (specifically the 3-Tier Architecture).
- Demonstrate proficiency in full-stack development using ASP.NET Core MVC and Node.js.
- Prove the ability to design and implement secure relational data access layers using SQL Server.
