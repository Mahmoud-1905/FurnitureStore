# 08 — Stitch Prompt

## Purpose
Define the prompts that will be sent to the Stitch AI system to generate UI/UX mockups for each page of the Ruqi Store application.

## Pages Included
1. **Home / Landing Page** – Hero image, featured categories, navigation bar.
2. **Product Catalog** – Grid layout, filters, pagination.
3. **Product Detail** – Image gallery, specifications, add‑to‑cart.
4. **Shopping Cart** – Item list, quantity controls, total summary.
5. **Checkout Flow** – Address form, order summary, payment placeholder.
6. **Order History** – List of past orders with status.
7. **Appointment Booking** – Date picker, time slots, product interest field.
8. **User Profile / Wishlist** – Personal info, saved items.
9. **Admin Dashboard** – User management, audit logs, reports.
10. **Store Manager Dashboard** – Inventory, orders, appointments.
11. **About Us** – Brand story, image gallery.
12. **Contact / Connect Us** – Contact form, studio address, social links.

## Prompt Template (example)
```
Generate a high‑fidelity mockup for the **{Page Name}** of a premium furniture e‑commerce site. Use a neutral color palette with an accent of deep navy. Include RTL support for Arabic. Provide responsive layout specifications for mobile, tablet, and desktop. Return the design as a markdown description plus a PNG image placeholder.
```
