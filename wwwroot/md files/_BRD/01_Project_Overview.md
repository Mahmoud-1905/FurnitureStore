# 1. Project Overview

## 1.1 Introduction
The **Ruqi Store System** is a bespoke, single-vendor, full-stack web application meticulously engineered for the furniture retail sector. Unlike generic e-commerce platforms, this system is tailor-made to address the unique purchasing behavior associated with high-ticket furniture items.

## 1.2 Core Concept
At its heart, the project bridges the gap between digital convenience and physical assurance. It provides an intuitive, highly visual online catalog where customers can explore the store's complete inventory, coupled with a robust physical showroom appointment booking system.

## 1.3 Strategic Value
By integrating an online storefront with an in-store viewing experience, Ruqi Store System aims to transform passive online browsers into confident, in-store buyers. This "phygital" (physical + digital) approach allows customers to shortlist items online and verify them in person, significantly reducing the friction traditionally associated with buying furniture online.

## 1.4 Architectural Approach
The system follows a strict 3-tier architecture, utilizing **ASP.NET Core MVC** for the presentation layer (strictly without frontend frameworks like React or Vue, adhering to technical constraints) and **Node.js/Express** for a powerful, scalable backend API. This ensures a clean separation of concerns, high maintainability, and robust performance.
